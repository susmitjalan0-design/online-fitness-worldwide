有益下背部健康的最佳核心训练：7个动作和一周示例

核心不只是腹肌。前侧、两侧、背部和髋部，一起工作。每周练2到3次。也要知道什么时候应该先看医生。一般信息，不是医疗建议或诊断。

背痛很常见。大多数会在几周内自行好转。有时会持续更久，或反复出现。[3]

英国国民医疗服务体系（NHS）的建议：保持活动，继续日常活动。不要长时间卧床。[3]

运动是各大指南都认同的一点。世界卫生组织表示，可以为慢性下背痛的成年人提供有组织的运动方案。这是一项有条件的推荐，证据确定性低。[1]英国国家卫生与临床优化研究所（NICE）建议在疼痛发作期进行团体运动。[2]

这份清单是为了让背部保持强壮。它不是治疗。如果你现在背痛，请先读文末的“开始之前”。

你需要一张垫子、一条弹力带、一个哑铃或装了重物的包，以及25到30分钟。

有益下背部健康的7个最佳核心训练

  1. 1死虫式（Dead bug）
  2. 2鸟狗式（Bird dog）
  3. 3侧平板，先跪姿再脚撑
  4. 4臀桥
  5. 5弹力带Pallof推
  6. 6单侧负重行走（Suitcase carry）
  7. 7髋铰链，然后罗马尼亚硬拉

  1. 1死虫式（Dead bug）

    为什么
    手臂和腿在动，躯干保持不动。这正是核心一整天在做的事。
    怎么做
    仰卧。双臂指向天花板。髋和膝屈曲90度。下背轻贴地面。呼气，一侧手臂向后伸，对侧腿向前伸直。只伸到背部还能贴地的程度。还原。换边。缩小幅度，让下背部始终轻轻贴住地面。
    训练量
    每侧6到10次，2到3组。慢。

  2. 2鸟狗式（Bird dog）

    为什么
    同样的思路，换成俯身。背部肌肉和臀肌在你伸展时稳住脊柱。
    怎么做
    双手在肩膀正下方，膝盖在髋部正下方。一侧手臂向前、对侧腿向后伸，直到与身体平齐。不要扭转。不要塌腰拱背。保持5秒。还原。换边。腰部塌陷？缩短力臂：膝盖或手在地面多停留，只把一侧肢体滑出去。
    训练量
    每侧6到8次，2到3组，每次保持5秒。

  3. 3侧平板，先跪姿再脚撑

    为什么
    躯干两侧防止你向侧面弯。每次单手提东西时，它们都在工作。
    怎么做
    侧卧，手肘在肩膀正下方，屈膝。抬起髋部，直到从头到膝成一条直线。保持呼吸。当30秒变得轻松，伸直双腿，改用双脚支撑。
    训练量
    每侧保持15到30秒，2到3次。

  4. 4臀桥

    为什么
    强壮的臀肌让髋部与下背部分担负荷。
    怎么做
    仰卧，屈膝，双脚踩地。收紧臀肌，抬起髋部，直到膝、髋、肩成一线。肋骨下沉。不要拱腰。停顿。慢慢放下。太轻松？改为单腿。
    训练量
    8到12次，3组。[9]

  5. 5弹力带Pallof推

    为什么
    核心的另一项工作：有东西把你往侧面拉时，不被带着扭转。抱孩子在一侧髋上。推一扇沉重的门。单肩背包。
    怎么做
    弹力带固定在胸口高度，用门锚或结实的柱子。侧身站立。双手在胸前握住弹力带。向正前方推出。别让它把你拉转。保持2秒。收回。没有弹力带？改做前臂平板支撑。
    训练量
    每侧8到10次，2到3组。平板支撑：保持20到30秒，2到3次。

  6. 6单侧负重行走（Suitcase carry）

    为什么
    一个重物，一只手。躯干必须对抗它保持直立。边走边练核心。
    怎么做
    单手拿哑铃、壶铃或装了重物的包。站直，双肩水平。慢慢走。不要向另一侧倾斜。换手。如果走路会加重症状，就用轻重量、走短距离。
    训练量
    每只手走20到30米或30秒，3到4趟。

  7. 7髋铰链，然后罗马尼亚硬拉

    为什么
    从地上拿东西是生活的一部分。髋铰链教你保持背部伸展、从髋部屈身。然后让腿和臀部强壮到足以做到。在一项针对慢性下背痛试验的大型分析中，力量训练在改善身体功能的运动类型中名列前茅。证据质量低。[5]
    怎么做
    先把一根扫帚杆贴在背上：头、上背和尾骨都碰到它。膝盖微屈。髋部向后推，直到感觉到腘绳肌。收紧臀肌站起来。然后在大腿前方拿着哑铃或包来做。
    训练量
    8到12次，3组。只有当每一次背部都保持伸展时才加重。[9]先用扫帚柄练1到2周再加重量。如果训练中或训练后症状沿腿向下扩散，就退回上一步。如果症状留在背部或减轻，就小心继续。

哪个动作最好，多久练一次，应该疼吗？

没有哪一个动作独占鳌头。一项纳入29项试验（2,431人）的Cochrane综述发现，针对慢性下背痛，“核心”运动控制训练并不比其他运动更好。作者表示，可以根据个人偏好、费用和安全性来选择。[6]

一项纳入89项研究（5,578名慢性下背痛患者）的网状分析中，普拉提在缓解疼痛方面排名最高，力量训练和核心稳定训练在改善功能方面排名最高。单纯拉伸并不比不治疗更好。证据质量低。[5]所以这份清单把核心控制和力量结合起来。

能帮多少？一项纳入249项试验的Cochrane综述发现，与不治疗相比，运动很可能减轻慢性下背痛：在0到100的量表上约15分。对日常功能的影响更小。[4]有用，但不是魔法。

预防也很重要。在8项共1,634人的试验中，单纯运动使下背痛风险降低了33%。作者建议每周2到3次，力量训练配合拉伸或有氧运动。[7]另一项综述发现，运动加健康教育降低了发作风险。单纯教育、护腰带和鞋垫似乎没有预防作用。[8]

像任何力量训练一样逐步进阶。从能做8到12次标准动作的版本开始。当你比目标多做1到2次，就加一点：负荷增加2%到10%，或换更难的版本。[9]

应该疼吗？第二天有些肌肉酸痛是正常的。在Cochrane综述中，报告的不良反应大多轻微，比如肌肉酸痛。[4]越来越重的疼痛就是另一回事了。停下来，去看医生。[3]简单的红绿灯。绿灯：轻微、局部、会消退的酸痛。黄灯：组内疼痛加重，就降低难度。红灯：尖锐疼痛、疼痛放射到腿、或夜间疼痛加重，就停下去看医生。

让背部更强壮的一周示例

仅为示例，不是处方。请根据你的身体、健康状况和经历调整。

  • 周一：核心A。热身、死虫式、侧平板、臀桥、单侧负重行走。
  • 周二：快走。
  • 周三：核心B。热身、鸟狗式、Pallof推、髋铰链、单侧负重行走。
  • 周四：散步，或休息。
  • 周五：再做一次核心A。
  • 周六：走得更久一些，或做你喜欢的运动。游泳、瑜伽、普拉提。
  • 周日：休息。
  • 两次核心训练之间休息一天。在办公桌前坐了一整天？经常起来活动。
  • 疼痛自查：轻微、很快消退的不适没关系。组内疼痛加重，就降低难度：减小幅度或减轻负重。尖锐疼痛、肿胀、疼痛沿手臂或腿向下放射、麻木、关节打软或卡住，就停下并去检查。我是教练，不是理疗师或医生。

背痛之后重新开始，并且已获准训练？Return很适合。每次45分钟，每月12次，隔天一次。每两次之间都休息一天。我们先重建动作，再增加负荷。我是教练，不是医生或理疗师。如果你有诊断，我们会在他们的建议范围内训练。

开始之前

一般信息，不是医疗建议。如果背痛几周后没有好转、影响日常活动、休息后不缓解或夜间加重，或伴有不明原因的体重下降，请去看医生。如果背痛同时出现以下情况，请立即就医：双腿疼痛、刺痛、无力或麻木；生殖器或肛门周围失去感觉；新出现的膀胱或排便控制问题；胸痛；发烧或全身不适；突然剧痛，或疼痛迅速加重；或在严重事故后出现疼痛。[3]ACSM的运动前筛查模型指出：如果你平时不运动、没有症状，也没有已知的心脏、代谢或肾脏疾病，可以在没有医疗许可的情况下从低到中等强度开始，逐步增加。如果有上述疾病或症状，请先取得医疗许可。[10]怀孕、刚生产、近期做过背部手术，或有已确诊的脊柱疾病？请询问医生或理疗师哪些动作适合你。如果疼痛向腿部放射或突然加剧，请停止。

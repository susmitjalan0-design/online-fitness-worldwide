忙碌父母的最佳力量训练：7个动作和一周示例

你每天都在抱孩子、提安全座椅、拎购物袋。那就为此而练。每周两次20分钟，再加几次零碎小练习，就是真正的开始。

你想变得更强。你有孩子、有工作，大约有20分钟。开始已经够了。

活动变少不是你的错觉。一项涵盖25组成年人的综述发现，家中有孩子的父母比没有孩子的成年人活动更少。母亲总体上比父亲活动更少。[4]这些研究大多是某一时间点的横断面调查和自我报告，所以差距的大小只能粗略参考。

世界卫生组织建议每周至少2天进行涉及所有主要肌群的肌肉强化训练。[1]英国国家医疗服务体系（NHS）把抱起和抱着孩子走算作肌肉强化活动。[2]你其实已经在练一些了。这份清单让它真正算数。

你需要一小块地面，一个哑铃或装了书的背包，一把结实的椅子或厨房台面，再加上孩子午睡、清晨或洗澡的时间。

忙碌父母的7个最佳力量训练

  1. 1高脚杯深蹲
  2. 2髋铰链，然后罗马尼亚硬拉
  3. 3俯卧撑：先撑台面，再到地面
  4. 4单臂划船
  5. 5后撤弓步
  6. 6单侧提箱行走
  7. 7死虫式

  1. 1高脚杯深蹲

    为什么
    一整天都在蹲下、站起。深蹲练的就是这个。腿、髋和躯干一个动作全练到。
    怎么做
    把哑铃或背包抱在胸前。双脚比髋略宽。坐到两脚跟之间，挺胸。站起。还没有负重？坐到椅子上再站起来。拿重物，别拿孩子。孩子会乱动。
    训练量
    8到12次，2到3组。[8]

  2. 2髋铰链，然后罗马尼亚硬拉

    为什么
    提安全座椅、搬洗衣篮、抱起赖在地上抗议的小孩，都是这个动作。臀部向后，背部拉长。
    怎么做
    双脚与髋同宽，膝盖微屈。臀部向后推，让双手沿大腿下滑。背部拉长。夹紧臀部站起。先把扫帚杆贴在背上学动作。再拿哑铃或背包。
    训练量
    8到12次，2到3组。

  3. 3俯卧撑：先撑台面，再到地面

    为什么
    推婴儿车、推沉重的门、陪玩后从地上起身，都需要推的力量。
    怎么做
    双手撑在厨房台面上，身体从头到脚跟成一条直线。胸口降到台面边缘。推开。12次觉得轻松？换更低的支撑：靠墙放稳的椅子，然后台阶，然后地面。
    训练量
    8到12次，2到3组。超过12次就换更低的支撑。

  4. 4单臂划船

    为什么
    每一次抱起都是一次拉。划船练背部，也平衡你在身前做的所有推和抱。
    怎么做
    一只手和一侧膝盖撑在结实的椅子或凳子上。或一只手撑台面，双脚前后站。另一只手拿哑铃或背包。拉向髋部。慢慢放下。背部平直。
    训练量
    每侧8到12次，2到3组。[8]

  5. 5后撤弓步

    为什么
    一次一条腿，就像抱着孩子上楼梯。它会暴露你较弱的一侧。
    怎么做
    站直。需要的话扶住台面。一只脚向后迈，后膝向地面下降。用前脚发力站起。一侧做完所有次数，再换另一侧。
    训练量
    每侧8到10次，2组。

  6. 6单侧提箱行走

    为什么
    一边肩上挎包，一边髋上抱娃，一只手提安全座椅。单侧负重训练躯干不歪。
    怎么做
    一只手拿一个哑铃或一个重袋子。站直，双肩齐平。慢慢走。别向另一侧歪。换手。
    训练量
    每只手走20到30米或30秒，3趟。

  7. 7死虫式

    为什么
    仰卧练躯干，不压脖子。它教你的肋骨和骨盆在手脚移动时保持稳定。
    怎么做
    仰卧，双臂向上，膝盖弯曲在髋部正上方。呼气，下背轻轻贴向地面。慢慢放下一只手臂和对侧腿。背部保持不动。回到原位。换边。最近刚生完孩子？先读“开始之前”。
    训练量
    每侧6到10次，2到3组。慢。

练多少就够，以及怎么挤出时间

一周的总量比某一天更重要。一项关于省时训练的综述发现，每周训练量比训练频率更重要。它给出的最低量：每个肌群每周至少4组，所用重量能举6到15次。[5]这份清单练两次短课就能达到。

同一篇综述列出一个最低组合：一个腿部推蹬动作（如深蹲），一个上肢拉，一个上肢推。[5]时间真的很紧？就做第1、3、4项。

成对地练。一组深蹲，接一组俯卧撑，再休息。这样配对（超级组）与传统训练相比，大约能把训练时间缩短一半，训练量不变。[5]用第一个动作的一组轻重量来热身。除非目标是柔韧性，否则不需要先做很久的拉伸。[5]

小剂量也有用。一项关于最低剂量训练的综述发现，短时训练，或者用很少甚至不用器械的短时、频繁练习（运动“零食”），可以提高年轻人和老年人的力量和身体功能。[6]烧水时做10个深蹲，也算。

练多少才值得？在一项纳入16项队列研究的综述中，肌肉强化训练与全因死亡、心血管疾病、癌症和糖尿病风险降低10–17%相关。风险降低最多出现在每周约30到60分钟。[7]这是观察性研究的关联，不是证据。但它指向的是每周两三次短课，而不是几个小时。

像任何力量训练一样逐步加量。当你比12次标准动作多做1到2次，就加一点：负荷增加2%到10%。[8]家里没有更重的哑铃？放慢下放速度，换更难的版本，或加一组。

忙碌父母的一周示例

仅为示例，不是处方。请根据你的身体、健康状况和经历调整。

  • 周一，20分钟（孩子午睡时，或家里人醒来前）：深蹲配俯卧撑，然后髋铰链配划船。每对2到3轮。最后做负重行走。
  • 周二：推着婴儿车散步，或步行接送上学。尽量快走。
  • 周三：只做零碎小练习。烧水时10个深蹲。午饭前5个台面俯卧撑。
  • 周四，20分钟：弓步配俯卧撑，然后划船配死虫式。每对2到3轮。最后做负重行走。
  • 周五：休息，或零碎小练习。
  • 周六：一起做点活动。公园、游泳、长距离散步。
  • 周日：休息。如果这周顺利，可以加第三次短课。
  • 错过一次？就算了。第二天不要加倍。

开始之前

一般信息，不是医疗建议。ACSM的运动前筛查模型指出：如果你平时不运动、没有症状，也没有已知的心脏、代谢或肾脏疾病，可以在没有医疗许可的情况下从低到中等强度开始，逐步增加。如果有上述疾病或症状，请先取得医疗许可。[9]刚生完孩子？NHS建议：活动量与怀孕前的活动水平相符，并加入力量训练。产后6到8周检查之后，如果你觉得可以，可以做强度更高的活动。如果怀孕前不运动，不建议做高强度活动。[2]腹直肌分离时，NHS建议一开始避免仰卧起坐、平板支撑和高冲击运动。如果产后8周分离仍然明显，或者出现漏尿、阴道与肛门之间有下坠感，请找医生（GP）或社区健康访视员。他们可以给出建议，必要时转诊。[3]剖宫产或分娩困难之后，请询问医生何时开始。在小孩不会钻到重物下面的地方训练，重物放在地上，不要放在架子上。用力时呼气。如果出现胸痛、头晕或剧痛，请停止。

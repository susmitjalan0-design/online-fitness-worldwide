最适合旅行的徒手训练：酒店房间里的7个动作和一周示例

没有健身房。没有器材。一张床、一把椅子、一个背包和一块地面。七个随身带走的动作。

作者：Susmit Jalan，Online Fitness Worldwide 教练。 更新于2026年10月29日

出门不等于停练。变的只是器材。仅此而已。

世卫组织建议成年人每周2天或更多天进行肌肉强化训练，练到所有主要肌群。[1]一个酒店房间就够了。

出行的日子意味着久坐：机场、航班、会议。世卫组织指出，用任何强度的身体活动（哪怕是低强度）替代久坐，都对健康有益。[1]站起来。在航站楼里走一走。

你需要一张床或一把结实的椅子、一个背包，以及能躺下的一块地面。二十到三十分钟。

最适合旅行的7个徒手训练动作

  1. 1后脚抬高分腿蹲
  2. 2俯卧撑：先抬高，再到地面
  3. 3单腿罗马尼亚硬拉
  4. 4背包划船
  5. 5屈体俯卧撑（派克俯卧撑）
  6. 6侧平板支撑
  7. 7爬楼梯或原地间歇

  1. 1后脚抬高分腿蹲

    为什么
    不用负重的腿部大动作。一条腿做两条腿的活，自身体重很快就变得有挑战。ACSM的建议里，除了双侧动作，也包括单侧动作。[2]
    怎么做
    后脚放在床上或身后结实的椅子上。垂直下蹲，直到后膝接近地面。用前脚发力站起。需要的话扶着墙。刚开始练？先做双脚着地的分腿蹲。在中等深度时前膝能稳定对准脚的方向，再把后脚垫高。只下到舒适的深度：后膝接近地面是目标，不是起点。垫后脚的东西必须稳固、不会滑动。
    训练量
    每条腿2到3组，每组8到12次。太轻松？下放用3秒，或者背上背包。

  2. 2俯卧撑：先抬高，再到地面

    为什么
    这就是你出差时的卧推。在一项针对18名年轻男性、为期8周的小型试验中，调整到相当于卧推最大重量40%负荷的俯卧撑，与同等负荷的卧推带来了相近的肌肉和力量增长。[3]在30名有经验的训练者中，加弹力带的俯卧撑在5周内的力量增长与卧推相当。[4]都是小型研究。但俯卧撑是真正的训练。
    怎么做
    开始时双手撑在书桌或床沿上。从头到脚跟成一条直线。胸口下放到双手之间。推起。然后改到地面。再然后双脚放到床上。
    训练量
    2到3组，每组8到15次。15次很轻松？加大角度难度，而不是做更多次。

  3. 3单腿罗马尼亚硬拉

    为什么
    髋铰链：腘绳肌和臀肌，再加上平衡。单腿站立，对大多数人来说自身体重就够了。
    怎么做
    单腿站立，一只手扶墙。膝盖微屈。髋部向后推，让另一条腿向后抬起。背部拉长。腘绳肌有拉伸感时停住。夹紧臀部站起。
    训练量
    每侧2到3组，每组8到12次。空着的手拎上背包来加负荷。

  4. 4背包划船

    为什么
    拉的动作。徒手计划常常漏掉它，代价由背部承担。世卫组织的建议覆盖所有主要肌群，背部也在其中。[1]装满的背包就是你的哑铃。
    怎么做
    把背包装满：水瓶、鞋子、装在保护套里的笔记本电脑。一只手和一侧膝盖撑在床上。背部平直。把背包拉向髋部，肘部贴近身体。停一下。慢慢放下。
    训练量
    每侧2到3组，每组10到15次。背包太轻？顶端停2秒。

  5. 5屈体俯卧撑（派克俯卧撑）

    为什么
    不用负重的过顶推。髋部抬高，让更多体重落在双手上方。
    怎么做
    从俯卧撑姿势开始。双脚往前走，抬高髋部，身体像一个倒V。屈肘，把头顶朝地面放下，落在双手稍前方。推回起始位置。
    训练量
    2组，每组6到10次。太难？双手撑在床上做。如果过顶推会痛，就跳过。

  6. 6侧平板支撑

    为什么
    从侧面练核心。在机场拖着行李箱时，就是它让你保持挺直。
    怎么做
    侧躺，肘部在肩膀正下方。抬起髋部，让身体成一条直线。开始时屈膝。觉得轻松后再伸直双腿。保持呼吸。
    训练量
    每侧2到3次，每次保持20到30秒。

  7. 7爬楼梯或原地间歇

    为什么
    体能部分。在一项为期6周的试验中，久坐的年轻人（每组12人）每天3次用力爬60级台阶，每次间隔1到4小时，每周3天。他们的体能（最大摄氧量）提高了，但提高幅度不大。[7]大多数酒店都有楼梯间。
    怎么做
    快步上楼，手靠近扶手。走下来。没有楼梯？原地高抬腿或快速踏步。强度要让你呼吸明显加重，但不至于动作变形。
    训练量
    爬3到5趟，或做5到8轮：20秒用力，40秒放松。

徒手训练够吗？最少练多少能保住成果？

加难度，不加时长。ACSM的起点是能举起8到12次的负荷；当你比目标多做1到2次时，增加2%到10%。[2]没有器械时，就改变杠杆：从抬高俯卧撑到地面，从双腿到单腿，放慢下放，背包装得更重。

轻负荷也有效。一项纳入21项研究的综述发现，每组做到力竭时，轻负荷和大负荷带来的肌肉增长相近。大负荷带来的最大力量更多。[5]所以徒手训练能保住并增长肌肉，但在最大力量上有上限。那是研究条件，不是训练指令。独自训练时，每组留1到3次余力。

一次出差不会抹掉你的努力。在一项试验中，成年人每周训练3天、持续16周，之后32周把训练量降到原来的三分之一或九分之一。两种剂量都保住了年轻人（20到35岁）的肌肉体积，但老年人（60到75岁）没有。即使是完全停练的那一组，力量也大部分保住了，只在最后略有下降。[6]

所以短途出行时，每周一两次扎实的训练就能保住你练出来的大部分成果。年纪大一些的话，多练一点，别少练。

一周旅行训练示例

仅为示例。不是处方。请根据你的身体、过往经历和这次行程调整。

  • 出行日：在航站楼里走动，别一直坐在登机口。长途航班上，在机组允许时站起来活动。
  • 第2天（A，25分钟）：5分钟热身，然后分腿蹲、俯卧撑、背包划船、侧平板支撑。2到3轮。
  • 第3天：步行逛城市。时间允许的话，爬一两趟楼梯。
  • 第4天（B，25分钟）：热身，然后单腿罗马尼亚硬拉、屈体俯卧撑、背包划船、爬楼梯或原地间歇。
  • 第5天：休息，或轻松散步。
  • 第6天（再做A）：上次觉得轻松的动作，加一次，或换更难的版本。
  • 第7天：返程。回到你平常的一周。

无论身在何处，想要实时指导？

Iron Hour是实时指导的力量与体能训练。60分钟，一对一。第0分钟准备：把手机或电脑放在我能看到你全身的位置。第4分钟开始热身。第14分钟开始主项。第28分钟辅助训练。第50分钟放松。

在酒店房间也能练，房间里有什么就用什么。计划会根据通话中看到的情况，配合行程调整。

停练后重新开始？Return：每次45分钟，每月12次，隔天进行。Lean Reset：每月20次，一对一。Open Floor是小组课。

开始之前

一般信息，不是医疗建议。ACSM的筛查模式指出：如果你平时不运动、没有症状，也没有已知的心脏、代谢或肾脏疾病，可以不经医生许可，从低到中等强度开始，逐步增加。如果你有上述疾病之一，或有胸痛、异常气短或头晕等症状，请先获得医生许可。[8]在房间里：用没有轮子的椅子，并靠墙放稳。确认地面不滑。上下楼梯时扶好扶手。如果你曾有过血栓，或医生提醒过你注意血栓，出行前请就长途飞行咨询医生。出现剧痛就停下；如果有关节问题、正在怀孕或刚生产不久，请先咨询专业意见。

ATHX是什么？赛制、训练与公开数据

依据ATHX官方页面和CrossFit公告：ATHX赛制、2026和2027训练、组别、装备规则、计分和总决赛资格。

ATHX自称是一项2.5小时、包含三个训练的健身比赛，考验力量和耐力。[1] CrossFit 2026年9月的公告称其为CrossFit官方合作赛事系列，是一项在全球举办、以adidas为首席合作伙伴的功能性健身比赛。[9]

TheProgrm报道，ATHX于2023年在英国创办，2025赛季的六场比赛有近6,000名运动员参加。[10]

本页为独立内容，并非ATHX或CrossFit官方发布。

官方规则所述的赛制

  1. 1赛制：2.5小时六个区域
  2. 2力量
  3. 3耐力
  4. 4MetCon X
  5. 5组别
  6. 6力量训练装备
  7. 7计分与总决赛

  1. 1赛制：2.5小时六个区域

    来源中
    热身30分钟、力量20、补给10、耐力30、恢复30、MetCon X 30，每次动作均有裁判。CrossFit称三个训练整个赛季保持不变，因此各赛事成绩可比。[1][9]

  2. 2力量

    来源中
    2026年个人：严格推举1RM（第0–6分钟）、后蹲3RM（6–12）、硬拉5RM（12–20）；以总重量计分。[2] 2027年个人：肩上推举1RM、后蹲2RM、硬拉3RM（两次尝试取平均）；以三项之和计分。[3]

  3. 3耐力

    来源中
    2026年个人：跑步和划船，限时22分钟，每750米（ATHX）或1公里（PRO）交换；以总距离计分。[2] 2027年：先跑固定距离（ATHX和PRO为3公里，LITE为2.4公里），再在24分钟内尽量完成SkiErg距离；以SkiErg距离计分。[3]

  4. 4MetCon X

    来源中
    2026年个人ATHX：SkiErg 45/30卡（男/女）、单臂哑铃地面到头顶30次（20/12.5公斤）、沙袋搬运30米（50/30公斤）、跳箱越过30次（24/20英寸）、哑铃行进弓步30米、波比跳远30米，再做SkiErg；限时25分钟。[2] 2027年以RowErg（45/35卡）取代SkiErg，并增加哑铃卧推、沙袋深蹲和越过软凳的波比。[3]

  5. 5组别

    来源中
    LITE（仅双人；负荷更轻、动作简化）、ATHX（核心组别，完整标准）和PRO（最重负荷、最严标准）。可单人或双人参赛。[1][9]

  6. 6力量训练装备

    来源中
    允许：镁粉、护膝和护肘套、举重腰带、举重鞋和护腕。不允许：助力带、护掌、护膝绷带、护肘绷带及专用支撑装备。[4]

  7. 7计分与总决赛

    来源中
    每名运动员根据各训练及其动作获得满分100的健身分数。[9] 2026年总决赛于11月27–29日在里斯本举行；每场赛事ATHX和PRO组（男女）前4名个人获得资格，邀请须在7天内接受，否则顺延。[6]

来自官方和第三方来源的数据

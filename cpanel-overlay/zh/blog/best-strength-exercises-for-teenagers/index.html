青少年最佳力量训练：7个动作和一周示例

只要技术优先、有合格的成年人监督，青少年可以安全地进行力量训练。轻负重，保留1到3次余力，让家长了解情况。

作者：Susmit Jalan，Online Fitness Worldwide 教练。 更新于2026年11月18日

青少年能举重吗？家长常问我这个问题。更好的问题是：怎么练。练得对，力量训练能让身体扛得住运动、长个子的阶段，以及久坐学习的长时间。

美国儿科学会（AAP）表示，只要重视正确技术并有良好监督，儿童和青少年可以通过抗阻训练增强力量，受伤率也低。不只是举重，自重动作也算。AAP还指出，多年来年轻人的肌肉体能指标一直在下降。[3]

误区。举重会让孩子长不高吗？AAP说，没有证据表明设计合理的训练会损害骺板（生长板）、身高或心脏。会练得太壮吗？青春期前，力量主要来自神经系统学会调动肌肉。青春期中和之后，肌肉本身也会增长。[3]

指南怎么说。WHO：5到17岁的孩子，一周内平均每天至少60分钟中等到较大强度、以有氧为主的活动，每周至少3天进行较大强度活动和强化肌肉与骨骼的活动。[1] NHS对5到18岁的建议相同，并补充：在合格成年人教会正确使用方法并进行监督的前提下，年轻人可以使用器械负重。[2]

研究显示了什么。一项针对18岁以下人群对照试验的荟萃分析发现，抗阻训练对肌肉力量的总体效应量为1.12。获得力量的能力似乎随年龄和成熟度增加，青春期并没有明显的跃升。训练周期更长、组数更多的效果更好。[7] 在6到18岁的青少年运动员中，一项纳入43项研究的荟萃分析发现，对力量和跳跃的效果为中等，对冲刺、灵敏性和专项表现的效果较小。[8]

受伤。一项纳入25项青少年运动研究的综述，汇总了神经肌肉训练项目的随机对照试验：下肢受伤风险更低（发生率比0.64）。膝关节受伤的估计方向相同，但没有统计学意义。[10] 一项关于青少年运动员的综述发现，举重的年轻人中报告的大多数伤害可归为意外，并指出缺乏合格指导、技术不良和负重不当，可能部分解释了其中一些伤害。[6]

健康。一项纳入110项研究的综述发现，年轻人肌肉更强与更少的全身和腹部脂肪、更好的心血管代谢风险因素、更好的骨骼健康以及更高的自尊相关。与肌肉骨骼疼痛和认知能力的关联不一致或不确定，而且多数关联为低到中等。[9] 这是在许多年轻人身上看到的关联，并不证明每一项都是举重造成的。

青少年抗阻训练有专门的指南：来自美国国家体能协会（NSCA）[4]，以及2014年一项得到运动医学、运动科学和儿科组织认可的国际共识。[5] NSCA的观点：成年人从抗阻训练中获得的许多益处，遵循适龄指南的儿童和青少年同样可以获得。[4]

这是教练指导，不是医疗。你是家长？请和孩子一起读。并先读“开始之前”。

青少年的7个最佳力量训练动作

  1. 1高脚杯深蹲
  2. 2髋铰链，然后罗马尼亚硬拉
  3. 3俯卧撑：先撑台面，再到地面
  4. 4单臂划船
  5. 5后撤弓步
  6. 6死虫式
  7. 7小跳和轻柔落地

  1. 1高脚杯深蹲

    为什么
    跳跃、冲刺和从地上站起来的基础。腿、髋和躯干。最先要掌握的动作。
    怎么做
    先不负重，双臂前伸。双脚略宽于髋。在两脚跟之间坐下去，胸口抬起，膝盖朝脚尖方向。站起。能标准地做12次？把一个轻哑铃或装了几本书的背包抱在胸前。
    剂量
    1到3组，每组8到12次。保留1到3次标准动作的余力（RIR）；动作变形前就停。

  2. 2髋铰链，然后罗马尼亚硬拉

    为什么
    背部保持伸长地捡起东西。这是硬拉的动作模式，也是好的跳跃的基础。
    怎么做
    把扫帚杆沿背部放好，接触头部、上背和尾骨。膝盖微屈。臀部向后推，直到大腿后侧有拉伸感。夯紧臀部站起。全程扫帚杆都贴着？再换成轻哑铃。
    剂量
    1到3组，每组8到12次。保留1到3次标准动作的余力（RIR）；动作变形前就停。

  3. 3俯卧撑：先撑台面，再到地面

    为什么
    运动和从地上起身需要的推力。用自身体重，按你的水平调整。
    怎么做
    双手撑在厨房台面或结实的桌子上，身体从头到脚跟成一条直线。胸口下到台边。推起。能标准做12次？再放低：台阶，然后地面。
    剂量
    1到3组，每组6到12次。只有每一次都保持身体笔直时才降低高度。保留1到3次标准动作的余力（RIR）；动作变形前就停。

  4. 4单臂划船

    为什么
    拉的动作平衡所有的推，也平衡低头看手机、伏案的时间。上背和握力。
    怎么做
    一只手和一侧膝盖撑在结实的长凳或椅子上，背部平直。另一只手拿哑铃或背包。拉向髋部。慢慢放下。
    剂量
    每侧1到3组，每组8到12次。保留1到3次标准动作的余力（RIR）；动作变形前就停。

  5. 5后撤弓步

    为什么
    一次一条腿，就像跑步、变向和上楼梯。能让你看出较弱的一侧。
    怎么做
    站直。需要的话扶墙。一只脚向后迈，后侧膝盖向地面下沉。用前脚发力站起。一侧做完所有次数，再换另一侧。
    剂量
    每侧1到2组，每组6到10次。保留1到3次标准动作的余力（RIR）；动作变形前就停。

  6. 6死虫式

    为什么
    躯干控制：手脚移动时，肋骨和骨盆保持不动。AAP认为核心训练是运动的基础。[3]
    怎么做
    仰卧，双臂向上，屈膝使膝盖位于髋部上方。呼气，下背轻轻贴向地面。慢慢放下一侧手臂和对侧腿。背部不动。还原。换边。
    剂量
    每侧1到3组，每组6到10次。慢。保留1到3次标准动作的余力（RIR）；动作变形前就停。

  7. 7小跳和轻柔落地

    为什么
    落地是一种技能。跳跃、落地和平衡练习属于综合神经肌肉训练，AAP表示它能改善运动技能并降低运动损伤风险。AAP也指出，在骨骼接近成熟之前，爆发性用力可能给肌腱附着处的生长区带来压力。所以跳跃要小、要少。[3]
    怎么做
    站直。用前脚掌做小幅弹跳，落地无声。然后向上小跳一次，轻柔落地：膝盖朝脚尖方向，臀部向后。停住2秒。落地安静就说明控制好。
    剂量
    2到3组，每组5次落地，穿鞋，在防滑地面上。组间充分休息。不跳箱，不从高处往下跳。脚跟疼，或膝盖骨正下方疼？先不做跳跃，并告诉家长。

练多少、多用力、多久一次

多久一次：每周2到3次，不要连续两天，每次至少20到30分钟。研究显示，每周2到3次、至少8周的训练能提高力量。在AAP引用的研究中，超过23周的训练计划力量提升最大。[3]

开始时练多少：学技术时，轻负重，1到2组，每组8到12次。技术稳定后，每次增加5%到10%的重量，并稍微减少次数。之后：低到中等负重，2到4组，每组6到12次。[3] 运动员研究中那种大重量、低次数的训练[8]要晚得多，需要很高的技术水平和面对面的教练指导，不是看博客就能练的。

休息：初学者组间约1分钟。训练越难，休息越长。[3]

多用力：保留1到3次余力。目标不是力竭。负重由技术决定，不是哑铃上的数字，也不是朋友的视频。

红绿灯自查，0到10分，每组进行中和结束后检查疼痛。绿灯，0到2：继续。黄灯，3到5：保持当前量，不再增加。红灯，超过5，或第二天早上更重：退一步，减小幅度、减轻负重或减少组数。关节疼、脚跟疼、膝盖骨正下方疼，或任何改变你动作方式的疼痛，都不算黄灯：停下来并去检查。这些颜色是教练的经验法则，不是研究结论。

把整周算进去。学校运动、体育课、训练和健身房都会累积。AAP建议把力量训练计入总训练时间，并建议每周至少有1到2天不参加竞技运动和专项训练。[3]

用动态活动热身，用轻松的拉伸放松。吃够、喝够：AAP表示，充足的能量对恢复和成长都很重要。[3]

有氧目标依然有效：一周内平均每天60分钟，以有氧为主。[1] 力量训练是在此基础上增加，而不是取代它。

青少年力量训练的一周示例

仅为示例，不是处方。请根据青少年的年龄、技术、运动项目和健康状况调整，并让父母或监护人参与。

  • 适用于健康的青少年：没有需要医生意见的疾病，目前没有受伤，并且父母或监护人同意。可以配合学校的运动安排。
  • 周一，约30分钟：热身、高脚杯深蹲、俯卧撑、单臂划船、死虫式。每个动作1到2组。
  • 周二：运动、体育课或活跃的游戏。
  • 周三：不做负重训练。走路、骑车、玩。
  • 周四，约30分钟：热身、小跳和轻柔落地、髋铰链、后撤弓步、俯卧撑、死虫式。每个动作1到2组。
  • 周五：运动或活跃的游戏。周六：比赛日，或长时间步行、骑车。
  • 周日：完全休息。
  • 本示例周的负重上限：自身体重，然后是能标准完成12次的轻哑铃或背包。不做最大重量、不测最大重量、不练到力竭、不从高处往下跳、不做计时训练。比赛后很累？先减一组，而不是取消一次训练。
  • 保留1到3次标准动作的余力（RIR）；动作变形前就停。
  • 疼痛自查：轻微、很快消退的不适没关系。组内疼痛加重，就降低难度：减小幅度或减轻负重。尖锐疼痛、肿胀、疼痛沿手臂或腿向下放射、麻木、关节打软或卡住，就停下并去检查。我是教练，不是理疗师或医生。

想要实时指导吗？

Iron Hour为60分钟一对一。第0分钟准备：摄像头能拍到你从头到脚，空出的地面，一把椅子，一根扫帚杆，一个轻哑铃或背包。未满18岁？父母或监护人在准备时到场，并且一直留在家中。第4分钟起热身。第14分钟主项。第28分钟辅助动作。第50分钟放松。

Lean Reset每月20次一对一，若你想更频繁的教练日。Return为45分钟一对一，每月12次隔日课，若你多年未训练。Open Floor是小团体。

我是教练，不是医生或理疗师。有疾病时，由医生决定什么是安全的。我先教技术，实时纠正，并告诉家长我们练了什么。不节食，不减重。提高成绩的违禁物质：绝对不行。

通过Google Meet、Zoom或FaceTime在你客厅直播指导。印地语或英语。印度标准时间。还不确定？先预约30分钟咨询。那是对话，不是训练课。预约锁定时间；费用当面约定。

开始之前

一般信息，不是医疗建议。未满18岁：父母或监护人应知情并同意。NHS建议：有健康问题时运动前先咨询医生；选择适合年龄、能力和经验的运动；慢慢开始，逐步增加；在合格成年人教导和监督下，年轻人可以使用器械负重。[2] AAP建议：有未控制的高血压、未控制的癫痫发作、某些心脏疾病，或曾接受蒽环类药物化疗，在开始抗阻训练前先咨询医生；复杂先天性心脏病应咨询儿科心脏科医生。患有肥厚型心肌病、肺动脉高压或马凡综合征时，AAP不建议进行抗阻训练。出现任何疾病、受伤或过度使用的迹象，都应先检查再恢复训练。[3] AAP还指出，报告的大多数举重相关伤害发生在家用健身器材上，在无人监督的环境中，且常伴有不安全的行为。[3] 所以：不要在家独自举大重量，不要冲击极限，任何杠铃都要上锁扣。担心饮食、体重或体型，或者有快速增肌的压力？请和医生谈谈：AAP建议对热衷竞技健美的青少年仔细筛查这些问题。[3] 胸痛、晕倒、心跳非常快，或与运动强度不相称的气喘：立即停止并寻求医疗帮助。

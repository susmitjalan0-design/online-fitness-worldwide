提升握力的最佳训练：7个动作和一周示例

握力拎起购物袋，拧开罐子，抓住横杠。每周练2到3次，放在力量训练的最后。十分钟就够。

作者：Susmit Jalan，Online Fitness Worldwide 教练。 更新于2026年11月2日

握力就是你双手和前臂的力量。你整天都在用它。提袋子、开罐子、抱孩子、推一扇沉重的门。

研究人员喜欢它，因为测起来很快：在握力计上用力握一下。握力能反映你整体力量的很多信息。[5]

在PURE研究中，17个国家（包括印度和阿联酋）的139,691名35到70岁成年人接受了握力测试。在约4年里，握力每低5公斤，任何原因导致的死亡风险就高16%。[2]

这是关联，不是证据。作者表示，还需要更多研究来检验变得更强是否能降低这一风险。[2]所以我们不追一个数字。我们练全身，双手也一起练。

你需要一两个哑铃（或装水的桶），一条毛巾，一根橡皮筋，以及力量训练后的10分钟。

提升握力的7个最佳训练

  1. 1农夫行走
  2. 2悬挂（Dead hang）
  3. 3毛巾划船
  4. 4捏握（Pinch hold）
  5. 5腕弯举和反向腕弯举
  6. 6握紧：握力器或软球
  7. 7橡皮筋张指

  1. 1农夫行走

    为什么
    双手拿重物，走起来。手在握，前臂在烧，肩和躯干让你保持挺直。最实用的握力训练。
    怎么做
    每只手拿一个哑铃、壶铃或一桶水。站直。肩膀下沉。慢慢走，小步走。在握不住之前放下，不要等到握不住。
    训练量
    走20到30米或30到40秒，3到4趟。

  2. 2悬挂（Dead hang）

    为什么
    用双手承担你的体重。练出持久的握力，并且整只手同时发力。
    怎么做
    只在能承受你体重的单杠或架子上做。踩着凳子上去。双手与肩同宽。悬挂时肩膀轻轻收紧，不要耸到耳朵边。太难？把脚留在凳子上，减掉一部分体重。
    训练量
    悬挂10到30秒，3次。中间休息一分钟。

  3. 3毛巾划船

    为什么
    毛巾是一个又粗又软的把手。手指得更用力才能握住。背部同时也做了划船。
    怎么做
    把一条小毛巾穿过哑铃把手，或绕过弹力带。单手握住两端。另一只手撑在椅子或凳子上。拉向髋部。慢慢放下。
    训练量
    每侧8到12次，3组。[8]

  4. 4捏握（Pinch hold）

    为什么
    大多数握力训练都忘了拇指。捏握专门练它。想象捏着边缘拿笔记本电脑或托盘。
    怎么做
    两片杠铃片，光滑面朝外。或两本厚书，或捏住一本重书的书脊。用手指和拇指捏住，手臂自然垂在身侧。保持。
    训练量
    每只手保持15到30秒，3次。

  5. 5腕弯举和反向腕弯举

    为什么
    让手腕屈曲和抬起的肌肉都在前臂上。两侧都练，保持平衡。
    怎么做
    坐下。前臂放在大腿上，手腕刚好伸出膝盖。拿一个轻哑铃或一瓶水。掌心朝上：手腕向上卷起，慢慢放下。再掌心朝下：抬起手背，慢慢放下。幅度小。不要甩。
    训练量
    每个方向12到15次，2到3组。用轻重量。

  6. 6握紧：握力器或软球

    为什么
    用力握拳，一次又一次。简单，在办公桌前也能做。
    怎么做
    选一个你能握合8到12次的握力器，或一个软球、一条卷起的毛巾。用力握紧。保持2到3秒。慢慢松开。
    训练量
    每只手8到12次，2到3组。12次变轻松后，换更硬的握力器。[8]

  7. 7橡皮筋张指

    为什么
    六个动作在握。一个在张。整天打字、整节课都在抓握的手，也需要练另一面。
    怎么做
    把一根粗橡皮筋套在手指和拇指靠近指尖的地方。对抗它把手完全张开。保持一秒。慢慢合上。
    训练量
    每只手15到20次，2到3组。

多久练一次、用多重，以及握力告诉你什么

世界卫生组织建议每周至少2天进行涉及所有主要肌群的肌肉强化训练。[1]握力训练就包含在其中。把它加在2到3次力量训练的最后。不要每天练：手和前臂也需要休息日。

和任何力量训练用同一个规则。选一个你能做8到12次标准动作的重量或版本。当你比目标多做1到2次，就加一点：负荷增加2%到10%。[8]静态保持类动作，先加时间，再加重量。

握力训练有用吗？一项纳入24项试验、3,018名老年人（平均年龄73岁）的综述中，运动方案提高了握力。提升幅度小。[7]直接针对该任务训练、或结合多种运动形式的方案效果看起来最好。[7]所以这份清单两者都做。

握力关联的不只是双手。在50万名40到69岁的英国成年人中，握力较低与更高的全因死亡风险，以及心血管疾病、呼吸系统疾病和多种癌症的死亡风险相关。[3]在6,089名45到68岁的健康男性中，握力最弱的三分之一在25年后出现生活自理困难的可能性，是最强三分之一的两倍以上。[4]

这些是关联，不是因果。握力弱往往伴随着全身肌肉弱，也伴随着疾病和营养不良。[5]光捏握力器改变不了这些。关键是全身的力量训练。握力是检查它的一个好方法。

医生也会看握力。在欧洲的肌少症（与年龄相关的肌肉流失）定义中，握力低是首先要查的指标：用握力计测量，男性低于27公斤，女性低于16公斤。[6]这是诊室里的检查，不是在家做的。如果你担心力量在下降，请咨询医生。

包含握力训练的一周示例

仅为示例，不是处方。请根据你的身体、健康状况和经历调整。

  • 周一：力量训练，然后农夫行走和捏握。
  • 周二：快走。
  • 周三：力量训练，然后毛巾划船和悬挂。
  • 周四：休息，或散步。如果你打字多，在办公桌前做橡皮筋张指。
  • 周五：力量训练，然后腕弯举和握紧。
  • 周六：把买的东西拎回家。这也算。
  • 周日：休息。
  • 每周练握力2到3天，绝不连续两天高强度练握力。

开始之前

一般信息，不是医疗建议。ACSM的运动前筛查模型指出：如果你平时不运动、没有症状，也没有已知的心脏、代谢或肾脏疾病，可以在没有医疗许可的情况下从低到中等强度开始，逐步增加。如果有上述疾病或症状，请先取得医疗许可。[9]每次静态保持都要持续呼吸。不要憋气，尤其是有高血压时。手、手腕、肘部或肩部疼痛，手部关节炎，近期受伤或手术，或者手指麻木、刺痛？请先询问医生或理疗师哪些动作适合你。只在固定牢靠、能承受你体重的横杠上悬挂，下来时踩到凳子上，不要直接跳下。如果出现剧痛，或手部麻木、刺痛，请停止。

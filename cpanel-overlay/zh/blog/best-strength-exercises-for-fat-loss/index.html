最适合减脂的力量训练：7个动作和一周示例

减脂主要靠少吃一点。举重帮你在减脂时保住肌肉。大多数日子走路，每周练力量2到3天。保留1到3次余力。

先说实话。当你吃喝进去的热量少于身体消耗的热量，脂肪才会减少。英国NHS这么说，负责制定英格兰临床指南的NICE也这么说。[2][3]没有哪种运动能绕过这一点。

那为什么还要举重？一项涵盖58项健康成人试验的综述发现，与不运动相比，全身力量训练让体脂率下降约1.5个百分点，脂肪量减少约半公斤，还减少了内脏脂肪，也就是包裹在器官周围的脂肪。[5]效果不大，但是真实的。而且你会变强。

走路依然重要。在STRRIDE AT/RT研究中，119名久坐、超重或肥胖的成人训练了8个月。有氧训练比单纯力量训练减掉了更多体重和脂肪。力量训练，无论单独还是结合有氧，都增加了更多瘦体重。[6]所以两样都做。

肌肉是你想保住的部分。一项针对160名参加减重计划的肥胖老年人的试验中，三个运动组都减掉了约9%的体重。力量组和结合组的瘦体重下降2%到3%，而单纯有氧组下降5%。结合组的身体功能改善最多。[8]

一项包含43项试验的Cochrane综述发现，单靠运动减重幅度很小，但运动加饮食比单靠饮食多减约1.1公斤。即使单靠运动，血压、甘油三酯和空腹血糖也有改善。[4]就算体重秤不动，运动也在帮你的健康。

这是训练指导，不是医疗。有健康问题或长期服药？开始前先问医生。请阅读“开始之前”。

最适合减脂的7个力量训练动作

  1. 1高脚杯深蹲
  2. 2哑铃罗马尼亚硬拉
  3. 3上斜俯卧撑
  4. 4单臂哑铃划船
  5. 5分腿蹲
  6. 6农夫行走
  7. 7死虫式

  1. 1高脚杯深蹲

    为什么
    大腿和臀部是你最大的肌肉。肌肉越大，每次动作做的功越多。
    怎么做
    把一个哑铃或一瓶装满水的瓶子抱在胸前。双脚略宽于髋。向下坐到两脚跟之间，胸口挺起，膝盖与脚尖同向。站直。太难？坐到椅子上再站起来。太容易？加重，或用3秒下蹲。
    剂量
    3组，每组8到12次。保留1到3次标准动作的余力（RIR）；动作变形前就停。

  2. 2哑铃罗马尼亚硬拉

    为什么
    练腿后侧和背部。就是你提包或抱孩子时用的髋铰链动作。
    怎么做
    站直，重物放在大腿前，膝盖微屈。臀部向后推，背部保持修长平直，让重物沿腿下滑。感到大腿后侧拉伸时停住，再向前推髋站起。太难？缩短幅度，手只到膝盖上方，不负重。太容易？加重，或下放更慢。
    剂量
    3组，每组8到12次。保留1到3次标准动作的余力（RIR）；动作变形前就停。

  3. 3上斜俯卧撑

    为什么
    胸、肩和手臂一个动作搞定。双手的高度决定难度。
    怎么做
    双手撑在厨房台面或结实的桌子上，略宽于肩。从头到脚跟成一条直线。胸口下降到台边，再推起。太难？双手撑墙。太容易？换更低的平面，最后到地面。
    剂量
    3组，每组6到12次。保留1到3次标准动作的余力（RIR）；动作变形前就停。

  4. 4单臂哑铃划船

    为什么
    拉的动作平衡推的动作。练上背和手臂，有助体态和提购物袋。
    怎么做
    一只手和一侧膝盖放在长凳或结实的椅子上，另一只脚踩地。背部平直。把重物拉向髋部，手肘贴近身体，再慢慢放下。太难？换轻一点，或用绑在门把手上的弹力带。太容易？加重，或在顶部停2秒。
    剂量
    每侧3组，每组8到12次。保留1到3次标准动作的余力（RIR）；动作变形前就停。

  5. 5分腿蹲

    为什么
    一次练一条腿。力量和平衡都练到，还能看出左右差异。
    怎么做
    大步前后站立，后脚跟抬起，一只手扶墙或椅子。垂直向下，直到双膝弯曲，再用前脚发力站起。太难？缩小幅度，双手扶稳。太容易？双手各拿一个哑铃。
    剂量
    每条腿2到3组，每组8到10次。保留1到3次标准动作的余力（RIR）；动作变形前就停。

  6. 6农夫行走

    为什么
    握力、肩膀和躯干一起工作。心率也会上来。
    怎么做
    双手各提一个重哑铃、袋子或水桶。站直，肩膀下沉，用短而稳的步子走。不要向一侧倾斜。太难？减轻重量或缩短距离。太容易？加重或走更远。
    剂量
    走3到4趟，每趟20到40米，或30到45秒。在握力和姿势还好的时候就停。

  7. 7死虫式

    为什么
    教躯干在手脚移动时保持稳定。一个温和的收尾动作。
    怎么做
    仰卧，双臂指向天花板，膝盖在髋部上方弯成90度。下背部贴住地面。慢慢放下一只手臂和对侧的腿，回来再换边。太难？只动腿，或用脚跟点地。太容易？更慢，伸得更远。
    剂量
    每侧2到3组，每组6到10次。保留1到3次标准动作的余力（RIR）；动作变形前就停。

练多少、多用力、多频繁

世界卫生组织对成人的建议：每周150到300分钟中等强度有氧活动，外加每周2天或以上针对主要肌群的力量训练。[1]

想减重，多动有帮助。ACSM指出，每周150到250分钟中等强度活动只能带来有限的减重，每周超过250分钟与具有临床意义的减重相关。它还指出，力量训练不会增加体重秤上的减重，但可能增加瘦体重和脂肪减少。[7]

NICE指出，大多数人可能需要每天45到60分钟中等强度活动来预防肥胖。减重后，可能需要每天60到90分钟才能避免反弹。并且要从你现在的体能出发，循序渐进。[3]走路也算。

速度：NHS建议稳步减重，每周约0.5到1公斤。只减掉体重的5%到10%，就可能改善健康。[2]

多用力：每组要感觉吃力但动作标准。保留1到3次余力。练到力竭不是目标。

疼痛红绿灯，0到10分，每组进行中和结束后评估。绿灯，0到2分：继续。黄灯，3到5分：保持原有训练量，不要加。红灯，超过5分，或第二天早上更糟：退一步，减小幅度、减轻负重或减少组数。这是教练的经验法则，不是研究结论。

进阶：当你以标准动作超过次数范围上限1到2次，就稍微加重，约2%到10%。[9]

冲击：示例周里没有跳跃，也没有跑步。快走就能完成有氧部分。这个限制是教练的选择，不是研究给出的上限。体重较大、膝盖不适的人，先打好基础效果更好。

减脂力量训练的一周示例

仅为示例，不是处方。请根据你的身体、健康状况和经历调整。

  • 周一，约40分钟：高脚杯深蹲、单臂划船、罗马尼亚硬拉、上斜俯卧撑。每个3组。最后做农夫行走。
  • 周二：快走30到45分钟。能说话，但唱不了歌。
  • 周三，约40分钟：分腿蹲、上斜俯卧撑、单臂划船、死虫式。最后做农夫行走。
  • 周四：快走、骑车或游泳，30到45分钟。
  • 周五，约40分钟：重复周一。
  • 周六：做一件你喜欢的活动：长距离散步、徒步、和孩子玩。
  • 周日：休息，或轻松散步。
  • 本示例周的负重上限：能流畅完成8到12次的重量。不做极限重量，不练到力竭，不跳，不跑。累了、压力大或没睡够？做一半，然后去走走。也算数。
  • 保留1到3次标准动作的余力（RIR）；动作变形前就停。
  • 疼痛自查：轻微、很快消退的不适没关系。组内疼痛加重，就降低难度：减小幅度或减轻负重。尖锐疼痛、肿胀、疼痛沿手臂或腿向下放射、麻木、关节打软或卡住，就停下并去检查。我是教练，不是理疗师或医生。

想要实时指导？

Iron Hour为60分钟，1:1。第0分钟准备：摄像头要能拍到你从头到脚，一两个哑铃、一把结实的椅子、一张垫子。第4分钟开始热身。第14分钟主项。第28分钟辅助练习。第50分钟放松。

Lean Reset每月20次一对一，若你想更频繁的教练日。Return为45分钟一对一，每月12次隔日课，若你多年未训练。Open Floor是小团体。

开始之前

一般信息，非医疗建议。ACSM筛查模型：若你久坐不动、无症状、无已知心脏/代谢/肾脏疾病，可在无医疗许可下开始轻到中等运动并逐渐加量。若有上述情况，或胸痛、异常气促或头晕等症状，先取得医疗许可。[10]力量训练不能代替医疗。NHS建议，如果你的BMI处于超重或肥胖范围，并且想要减重帮助、腰围超过身高的一半、患有糖尿病、高血压、关节痛或睡眠呼吸暂停等疾病，或者你有或怀疑自己有进食障碍，请去看全科医生。使用减重药物时，它说仍需要低热量的均衡饮食和规律活动。[2]在英国以外，就是看你的医生。膝盖、髋部或背部疼？每个动作从简单版本开始，逐步加量。出现胸痛、异常气喘、头晕或快要晕倒时，立即停止。

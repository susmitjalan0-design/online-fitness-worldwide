护膝友好的最佳腿部训练：7个动作和一周示例

腿要有力，膝盖要安稳。深度由你选。负重慢慢加。髋部也要出力。

上楼梯时膝盖不舒服。或者有人说深蹲伤膝盖。但你还是想要有力的双腿。很好。有力的双腿就是计划本身。

针对膝骨关节炎，一篇Cochrane综述汇总了44项试验。运动让疼痛在0到100分的量表上降低约12分，身体功能改善约10分。[4]英国NICE把治疗性运动列为核心治疗，并点名提到局部肌肉强化。[3]

针对髌骨周围的疼痛（髌股疼痛），一份国际专家共识支持运动疗法，尤其是髋部训练与膝部训练结合。[5]

世界卫生组织建议每周2天或以上，对所有主要肌群进行肌肉强化训练。[1]腿部也在其中。这份清单让训练对膝盖友好：深度由你定，负重慢慢加，髋部和膝盖一样出力。

这是训练，不是治疗。膝盖肿胀、卡住或打软？请先阅读“开始之前”。

护膝友好的7个最佳腿部训练

  1. 1箱式深蹲
  2. 2上台阶
  3. 3罗马尼亚硬拉
  4. 4臀桥
  5. 5侧卧抬腿
  6. 6分腿蹲
  7. 7坐姿伸膝

  1. 1箱式深蹲

    为什么
    深度由你选，每一次都停在同一个位置。深蹲时，膝盖弯曲越多，膝关节受力越大。在动作的上半段受力最小。[7]这只是一般规律。每个人的反应不同，所以按舒适度和控制力来选深度，而不是按受力图。
    怎么做
    站在一把结实的椅子或箱子前，双脚与髋同宽或略宽。双臂前伸，或在胸前抱一个重物。向后向下坐，直到刚好碰到座面。不要跌坐。站起。膝盖与脚尖同一方向。太难？加个靠垫，坐高一点。
    训练量
    2到3组，每组8到12次。当12次感觉轻松又平稳时，把座面稍微降低。如果第二天膝盖酸痛加重并持续24小时，就把箱子再调高。

  2. 2上台阶

    为什么
    楼梯、路沿、上坡。一次一条腿，高度由你选。
    怎么做
    从低处开始：家里最下面一级台阶就行。整只脚踩上台阶。用这只脚发力站直。另一只脚慢慢放下，不要掉下去。扶住栏杆或墙。只有在仍然舒适时才加高。不要在加负重的同一周加高台阶。
    训练量
    每条腿2到3组，每组8到10次。

  3. 3罗马尼亚硬拉

    为什么
    腘绳肌和臀肌做功。膝盖保持微屈，几乎不动。膝盖不太舒服的日子里，这是很好的腿部动作。
    怎么做
    双脚与髋同宽，膝盖放松。拿一个哑铃或背包。臀部向后推，让重物沿大腿滑下。背部保持伸长。感到腿后侧有拉伸时停住。夹紧臀部站起。
    训练量
    2到3组，每组8到12次。[9]

  4. 4臀桥

    为什么
    从地面练髋部力量。针对髌骨周围的疼痛，一篇综述发现髋部训练加大腿训练能减轻疼痛、改善功能，并有一些证据显示在1年时比单练大腿帮助更大。[6]
    怎么做
    仰卧，屈膝，双脚平放。用脚跟发力把臀部抬起，直到膝、髋、肩成一条线。夹紧。慢慢放下。太简单？改成单腿，或在髋部放一个重物。只有双腿版本完全不痛时才改单腿，并留意第二天膝盖的感觉。
    训练量
    2到3组，每组10到15次。

  5. 5侧卧抬腿

    为什么
    练髋部外侧，也就是单腿站立时让骨盆保持水平的肌肉。髋部训练是专家共识支持内容的一半。[5]
    怎么做
    侧卧，下方膝盖弯曲。上方的腿伸直，与身体成一线，脚尖朝前。把上方的腿抬起约一掌高。慢慢放下。身体不要向后翻。太简单？在膝盖上方加一根弹力带。
    训练量
    每侧2到3组，每组12到15次。

  6. 6分腿蹲

    为什么
    双脚着地的单腿力量训练。不跳，不上台阶。深度由你定。
    怎么做
    一脚在前，一脚在后，像迈了一大步。扶墙或椅子。后侧膝盖向地面下降，只降到仍然舒适的位置。前侧膝盖在脚掌中间上方。用前脚发力站起。一侧做完所有次数，再换另一侧。头2周，扶墙或扶椅是必须的，不是可选的。
    训练量
    每条腿2组，每组8到10次。

  7. 7坐姿伸膝

    为什么
    单独练大腿前侧（股四头肌）。膝部训练是专家共识支持内容的另一半。[5]不需要器械。
    怎么做
    坐直在椅子上。用踝部沙袋，或把弹力带套在椅腿和脚踝上。膝盖伸直到仍然舒适的程度即可，不必每次都完全锁直。伸直会刺激膝盖的话，从中段幅度开始，或换更轻的弹力带。只有疼痛轻微且在训练中就能消退时，才停顿2秒。用3秒放下。还没有负重？腿本身就够了。
    训练量
    每条腿2到3组，每组10到15次。

蹲多深、多重、多久一次

深度是一个旋钮，不是规定。深蹲时越往下，膝关节受力越大，接近最低点时达到峰值。同一篇综述发现，平行深蹲（大腿与地面平行）对健康的膝盖没有造成损伤。[7]

深蹲要不要更深？综述的看法不同。一篇认为对健康膝盖来说，平行蹲比深蹲更合适。[7]另一篇的结论是：在专业指导下学会技术、负重逐步增加，深蹲并没有增加受伤风险。它还提醒，用非常大的重量做半蹲和四分之一蹲，并不像看起来那么安全。[8]所以：深度要一点点挣来。蹲到仍然顺畅、平稳的位置。

髋和膝一起练。针对髌骨周围的疼痛，2018年的共识支持运动疗法，尤其是以髋为主和以膝为主的训练结合。[5]第4和第5项练髋。第1、2、6、7项练膝。第3项主要练髋。

被诊断为膝骨关节炎？NICE建议向患者说明：刚开始运动时关节疼痛可能会加重，但规律、持续的运动仍然对关节有益。[3]请问问你的医生或物理治疗师，多少运动量适合你。

坚持下去。在Cochrane综述中，正式训练计划结束后2到6个月，疼痛的减轻仍然存在。一对一的计划往往比集体课或居家计划效果更好，不过各研究差异很大。[4]

每周两次就达到世界卫生组织的最低建议。[1]当你能比12次多做1到2次标准动作时，稍微加一点：负重增加2%到10%。[9]没有更重的器械？下放更慢、箱子稍微降低，或加一组。

护膝友好的腿部力量一周示例

仅为示例，不是处方。请根据你的身体、健康状况和经历调整。

  • 周一，约30分钟：箱式深蹲、罗马尼亚硬拉、臀桥、侧卧抬腿。每个动作2到3组。
  • 周二：轻松散步或骑车。
  • 周三：休息，或散步。
  • 周四，约30分钟：上台阶、分腿蹲、坐姿伸膝、臀桥。每个动作2到3组。
  • 周五：休息。
  • 周六：做点你喜欢的。散步、游泳、骑车。
  • 周日：休息。
  • 第二天膝盖不舒服？课照上，但缩小：座面更高、台阶更低、重量更轻。
  • 疼痛自查：轻微、很快消退的不适没关系。组内疼痛加重，就降低难度：减小幅度或减轻负重。尖锐疼痛、肿胀、疼痛沿手臂或腿向下放射、麻木、关节打软或卡住，就停下并去检查。我是教练，不是理疗师或医生。

想要实时指导？

Iron Hour是60分钟，一对一。第0分钟准备：摆好摄像头，让我能看到你的脚、膝盖和髋部。第4分钟开始热身。第14分钟进入主项，按我们约定的深度。第28分钟做辅助练习。第50分钟放松。

Return每次45分钟，一对一，每月12次，隔天一次。为因膝盖不适、长期中断或生活忙碌而停练的人设计。我们先打基础。

开始之前

一般信息，不是医疗建议。ACSM的运动前筛查模型指出：如果你平时不运动、没有症状，也没有已知的心脏、代谢或肾脏疾病，可以在没有医疗许可的情况下从低到中等强度开始，逐步增加。如果有上述疾病或症状，请先取得医疗许可。[10]NHS建议：如果膝盖疼痛几周内没有好转，请去看全科医生（GP）。如果膝盖非常疼、无法活动或无法承重、明显肿胀或变形、出现卡住、打软或伴随疼痛的弹响，或者高烧并伴有膝盖周围发红发热，请立即寻求紧急建议。不痛的弹响是正常的。[2]在英国以外，这意味着去看你的医生或当地急诊。最近膝盖受过伤或做过手术？请先遵循外科医生或物理治疗师的方案。在不打滑的地面上训练。如果出现剧痛、胸痛或头晕，请停止。

改善平衡、预防跌倒的最佳训练动作：7个动作和一周示例

平衡是一种技能。站着练，每周难一点，它就会进步。手扶台面。双腿有力。保留1到3次余力。

也许你在楼梯上晃了一下。也许父母中有人去年冬天摔倒了。也许你只是觉得脚下不如以前稳。这种感觉值得重视。平衡是可以练的。

世卫组织建议65岁以上的人每周3天或以上进行多样的多组分活动，强调功能性平衡和力量，强度为中等或以上，以改善功能、预防跌倒。[1] NHS把随年龄增长而来的肌肉变弱列为跌倒原因之一，并建议每周至少两次力量和平衡活动。[2]

一项纳入108项试验的Cochrane综述发现，运动使居家老年人的跌倒率降低约23%，跌倒人数减少约15%。证据确定性被评为高。以平衡和功能性练习为主的方案效果最好。大多数是站着做的。[5]

一项纳入88项试验的荟萃分析发现，当方案对平衡的挑战较高、且每周超过3小时时，效果更大。两者结合与跌倒减少约39%相关。[6]

2022年世界跌倒预防指南建议进行挑战平衡的功能性练习，如坐站起立和迈步，每周3次或以上，个体化，并逐步加量至少12周，之后持续进行。条件允许时，建议同时加入渐进式力量训练。[4]

这份清单是训练指导，不是跌倒风险评估。如果你已经摔倒过，或感到头晕、站不稳，请先看医生。请先读「开始之前」。

改善平衡、预防跌倒的7个最佳动作

  1. 1坐站起立
  2. 2脚跟对脚尖：先站，再走
  3. 3单腿站立
  4. 4侧向行走
  5. 5上台阶
  6. 6提踵和勾脚尖
  7. 7站姿侧抬腿

  1. 1坐站起立

    为什么
    从椅子上站起来是你每天都需要的动作。世界指南点名把它列为功能性练习。[4]
    怎么做
    坐在结实椅子的前部，双脚与髋同宽，台面或桌子在手边。身体前倾，鼻子在脚尖上方，站起来。慢慢、有控制地坐下。太难？用更高的座位，或双手撑大腿借力。太容易？双臂交叉，再放慢下坐速度。
    剂量
    2到3组，每组8到12次。 保留1到3次标准动作的余力（RIR）；动作变形前就停。

  2. 2脚跟对脚尖：先站，再走

    为什么
    窄支撑面是对平衡的直接挑战。脚跟对脚尖行走是NHS居家平衡练习之一。[3]
    怎么做
    站在厨房台面旁，指尖轻扶台面。把一只脚的脚跟放在另一只脚脚尖正前方。目视前方，不看脚。保持。稳了之后，沿着台面脚跟对脚尖地走。太难？双脚并拢站，再前后错开半步。
    剂量
    左右脚各在前，保持10到30秒，各3次；或走2到3趟，每趟5到10步。 在稳定的边缘练习：可以晃，但永远不需要用力抓。手始终在台面可及之处。

  3. 3单腿站立

    为什么
    每走一步、上楼梯、穿裤子时，你都在单腿站立。它是NHS平衡练习的一部分。[3]
    怎么做
    面对台面，指尖轻扶。把一只脚稍稍抬起。骨盆保持水平，支撑腿膝盖微屈。保持，然后换腿。按这个顺序进阶：双手、单手、一根手指、双手悬空。之后再尝试移动视线或转头。
    剂量
    每条腿保持5到10秒，3次，逐步增加到30秒。 在稳定的边缘练习：可以晃，但永远不需要用力抓。手始终在台面可及之处。

  4. 4侧向行走

    为什么
    很多跌倒发生在转身或侧向迈步时。侧步可以慢慢训练这一点。它也在NHS的练习中。[3]
    怎么做
    站在台面旁，身体挺直，膝盖微屈。一只脚慢慢向侧面迈出，另一只脚跟上并拢。骨盆保持水平。沿台面走过去再回来。太难？步子小一点，手扶台面。太容易？慢速交叉步，一只脚从另一只脚前方交叉。
    剂量
    每个方向沿台面走2到3趟。 在稳定的边缘练习：可以晃，但永远不需要用力抓。手始终在台面可及之处。

  5. 5上台阶

    为什么
    楼梯和路沿需要单腿力量和控制。世界指南把迈步列为应纳入的功能性练习。[4]
    怎么做
    用最下面一级台阶，一只手扶栏杆。一只脚踏上去，全脚掌发力，站直。另一只脚慢慢下来。做五次，然后换另一条腿先上。太难？用更矮的台阶，或多借手的力。
    剂量
    每条腿2到3组，每组5到10次。 保留1到3次标准动作的余力（RIR）；动作变形前就停。

  6. 6提踵和勾脚尖

    为什么
    有力的脚踝帮你在绊到时稳住。一项居家力量与平衡训练让80岁及以上女性的跌倒和受伤跌倒都减少了。[8]
    怎么做
    扶住台面。踮起脚尖，停一下，慢慢放下。然后重心移到脚跟，抬起脚尖。太难？先坐着做。太容易？单腿做，仍然扶着。
    剂量
    2到3组，每组10到15次。 保留1到3次标准动作的余力（RIR）；动作变形前就停。

  7. 7站姿侧抬腿

    为什么
    髋部外侧肌肉在单腿站立时让骨盆保持水平。更强的髋部给平衡动作打下基础。
    怎么做
    侧身对着台面，一只手扶住。外侧腿向侧面抬起，脚尖朝前，身体挺直。慢慢放下。换边。太难？抬低一点。太容易？在膝盖上方套一根轻弹力带。
    剂量
    每侧2到3组，每组8到12次。 保留1到3次标准动作的余力（RIR）；动作变形前就停。

练多少、多用力、多久一次

世卫组织对65岁以上人群：每周3天或以上功能性平衡和力量训练，加上150到300分钟中等强度有氧活动，以及每周2天或以上针对主要肌群的力量训练。[1]

世界指南：每周3次或以上挑战平衡的功能性练习，至少逐步进阶12周，之后继续。[4]坚持更久，效果更大。

剂量很重要：平衡挑战高、每周超过3小时的方案效果最好。[6]可以是大多数日子做短时训练，再加上步行。在健康老年人中，每周约3次、持续11到12周的平衡训练，在平衡测试中提升最大。[7]

高挑战不等于高风险。意思是动作难到你需要集中注意力，同时支撑物始终在手边。减少支撑、缩窄站距、放慢动作或转头，都会让它更难。

力量进阶：当你比次数范围上限多做1到2次时，稍加负重，约2%到10%，或放慢下放速度。[9]保留1到3次余力。力竭不是目标。

步行有益，但Cochrane综述未能证明单靠步行可以预防跌倒。最明确的益处来自平衡和功能性练习。[5]

平衡与力量训练的一周示例

仅为示例，不是处方。请与医生一起，根据你的身体、用药和病史调整。

  • 周一，约30分钟：坐站起立、脚跟对脚尖站立、单腿站立、上台阶、提踵和勾脚尖。每个动作1到3组。
  • 周二：步行20到30分钟，速度以还能说话为准。烧水时在台面旁做5分钟单腿站立。
  • 周三，约30分钟：坐站起立、侧向行走、脚跟对脚尖行走、站姿侧抬腿。每个动作1到3组。
  • 周四：步行，加10分钟平衡保持练习。
  • 周五，约30分钟：重复周一。
  • 周六：散步，或附近有的话上一节太极课。
  • 周日：休息。
  • 本示例周负荷上限：自重或轻重量，能顺畅完成8到15次，支撑物始终在手边。不跳、不单脚跳、不用平衡板，除非理疗师安排，不做闭眼练习。
  • 保留1到3次标准动作的余力（RIR）；动作变形前就停。
  • 疼痛自查：轻微、很快消退的不适没关系。组内疼痛加重，就降低难度：减小幅度或减轻负重。尖锐疼痛、肿胀、疼痛沿手臂或腿向下放射、麻木、关节打软或卡住，就停下并去检查。我是教练，不是理疗师或医生。

想要教练实时指导？

开始之前

一般信息，非医疗建议。ACSM筛查模型：若你久坐不动、无症状、无已知心脏/代谢/肾脏疾病，可在无医疗许可下开始轻到中等运动并逐渐加量。若有上述情况，或胸痛、异常气促或头晕等症状，先取得医疗许可。[10]无论该模型怎么说，如果你摔倒过、感到头晕或要晕倒，或担心自己的平衡，请先看医生。NHS建议：如果摔倒过或担心平衡，请看全科医生。如果有人摔倒，可能伤到头、背、颈或髋部，或无法起身，请拨打急救电话。如果你认为某种药物影响平衡，请咨询医生或药剂师，并检查视力和听力。[2]在英国以外，即联系你的医生或当地急救号码。在干净、防滑的地面上训练，穿抓地好的鞋，台面或结实的椅子在手边。如果站不稳，最初几次请有人在旁边。出现头晕、胸痛、突然无力或麻木，或新的头痛时立即停止。

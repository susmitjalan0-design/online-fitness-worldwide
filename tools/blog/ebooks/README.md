# Ebook files

Covers (`covers/`) and sample-chapter PDFs (`samples/`) for the ebook block. Paths in `../data/ebooks.json` are relative to this
folder. The build copies only the files a rendered block uses to `cpanel-overlay/ebooks/`. See "Ebook block" in `../README.md`.

No ebook exists yet, so this folder holds no covers or PDFs. Never commit dummy or preview files here.
